# Commit Convention

Use conventional commits format:
- `feat(scope):` — new feature
- `fix(scope):` — bug fix
- `chore:` — maintenance, config, tooling
- `docs:` — documentation only
- `refactor(scope):` — code restructuring without behavior change
- `style(scope):` — formatting, whitespace

Scopes: `frontend`, `backend`, `docker`, or omit for root-level changes.
Keep commit messages concise (under 72 chars for subject line).
